# FE UI（apps/web）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Figma プロトタイプ（60 画面）を `apps/web` にモックデータで実装し、Service インターフェースで API 差し替え可能（Backend Ready）にする。

**Architecture:** Next.js 16 App Router + Tailwind v4（Figma 由来 tokens.css）+ 自前 DS プリミティブ（radix-ui / cva）。画面は `lib/api/services.ts` のインターフェースにだけ依存し、`mock/`（既定）と `http/`（Hono RPC）を `NEXT_PUBLIC_API_MODE` で切替。状態は TanStack Query。

**Tech Stack:** Next 16.3 / React 19 / TypeScript 6 strict / Tailwind 4.3 / radix-ui / class-variance-authority / clsx / tailwind-merge / lucide-react / motion / @tanstack/react-query / zod（shared）/ vitest + jsdom + @testing-library/react

**Spec:** `docs/superpowers/specs/2026-08-26-fe-ui-design.md`（画面定義は `docs/specs/ui-screens.md` v0.2、Figma ノード対応表は spec §7）

## Global Constraints

- TypeScript `strict` + `noUncheckedIndexedAccess` + `verbatimModuleSyntax`。`any` 禁止（Biome error）。識別子は英語、コメント・文言は日本語可。
- 外部入力（HTTP 応答）は zod で検証してから使う（`http/` 実装）。
- 角丸は常に 0。色・余白・線幅・フォントは `tokens.css` の変数 / `@theme` ユーティリティのみ（生の hex / px を書かない）。
- 文言は `docs/specs/ui-screens.md` と Figma のフレームに従う。専門用語はバッジに日本語ラベル。
- 各タスクは `pnpm --filter @dopamin/web test` と `pnpm lint` をグリーンにしてからコミット。PR 前に `pnpm check`。
- Next 16 の API は `node_modules/next/dist/docs/`（apps/web から解決）を読んでから使う（`proxy.ts` = middleware、`LayoutProps<"/">` グローバル型、`params` は Promise）。
- Figma の見た目は `get_design_context`（figma-design-to-code スキル）で spec §7 のノード ID を取得して合わせる。
