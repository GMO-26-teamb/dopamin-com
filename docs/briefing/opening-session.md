## ③ プログラム内容

### 開発の注意事項

- ソースコードは各チームで準備・管理してください
  - 例年はGitHub使ってるチーム多め
- お題は共通ですが、**各チームなりのアレンジを必ず加えてください**（以下は一例）
  - ターゲットユーザーを先に絞る（法人向け／個人向け、初心者向けなど..）
  - システム運用まで見据えた設計にする（障害対応、AIによる自律運用 等）
  - UI/UXデザインにこだわる、独自機能を組み込む、などなど..
- AIツールは、**Claudeをメインに使い倒してください**
  - 他のAIツールと併用での運用開発を見越した設計にするのはOK
- 開発完了後はアプリを**デプロイ**してください。デプロイ先に指定はございません。

### Claudeについて

- AIモデルの訓練・改善の設定はOFFにすることを推奨
  - 設定 → プライバシー → 『AIモデルの改善にご協力ください』
- トークンをガンガン使う作業をしている場合は、使用量に気を配ってください
  - 設定 → 使用量
- 万が一Claudeが使えなくなった場合は、他のAIツール・モデルで代用してください
