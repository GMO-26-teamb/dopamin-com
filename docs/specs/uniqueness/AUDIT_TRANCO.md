# 実 Tranco コーパス監査 (AUDIT_TRANCO)

実施日: 2026-08-26 / 対象: 独自性スコア v3.4-r2-ts.1 × 既定コーパス
`tranco-74V4X-2026-08-26-top10k+curated-v1`(Tranco 8,892 + curated 58 = 8,950 件、重複は popularity 高い方を採用)

目的: 較正時の擬似コーパス(129件)から実コーパス(8,950件)へ移行したときの挙動変化を測る。
**本監査ではラベル・数式・閾値の変更は行っていない**(発見事項は記録のみ)。

## 3. 系統攻撃 miss 11件(1.1%)の内訳

- `www` + 4文字以下の名前(wwwzoom, wwwdzen 等): `www` は接辞リスト外・4文字名は包含カーブ対象外(名前5文字以上)という既知の限界の組合せ。
- `witter`(twitter−1文字): hunspell 実在語のため一般語免除が作動(weighted<0.95)。実在語×有名名近傍の既知トレードオフ。
- `kam`(akam−1文字): 3文字化により短名モード。

対応候補(未適用): `www` を接辞リストへ追加 / 包含カーブの名前長ゲート見直し。いずれも較正へ影響するため、適用する場合は gold 再検証とセットで行うこと。

## 4. 実在語・包含語の low 化(64語スポット)

low 22件の内訳を精査すると2群に分かれる:

- **正当な low(コーパス実在名との完全一致)**: deadline / box / fox / office / windows / online 等は top10k に同名ドメインが実在(deadline.com, box.com, …)。「その名前は既に有名」なので low は正しい。
- **既知トレードオフによる low(0.95ガード超え)**: striped/stripes(→stripe 7点), canvas(→canva 10点), reactor/reacts(→react), mediums(→medium), applet(→apple), googol(→google), notebook(→**notebooklm** 15点。FA回帰の唯一の悪化), officer(→office), cloudy(→cloud) 等。一般語免除は weighted≥0.95 で外れる設計のため、有名名と極近の実在語は救済されない(DESIGN_RATIONALE「既知の限界」に記載済みの挙動)。

## 5. 造語FAベースレート 5.9%(low)の分析

low 例: rira(→jira) / legoj(→lego) / kita(→kit) / suno(→suno **完全一致**: 実在AIサービス) / monma(→mona) 等。
実コーパスには 3〜4文字の有名名が大量に含まれる(hud, kia, kit, bip, faa, …)ため、短い造語の近傍に「本当に実在する有名名」が現れる確率が構造的に上がる。上例の大半は実際に紛らわしい(=正しい検出)が、mid 19.7% と合わせ、体感として「造語でも満点が出にくい」方向へ変わることは製品挙動として認識しておくこと。

## 6. 性能

8,950件コーパス・プレフィルタ1有効で p50 117ms / p95 218ms / p99 245ms / max 281ms(bun, コンテナ実測)。
`/domains/check` は SLD 単位でリクエスト内メモ化するため、`sld+tlds` 形式(最大22 TLD)でもスコア計算は1回。`names` 形式で最大20 SLD の場合は最悪 ~4-5 秒になり得る(逐次)。AC-05-3(1件1.5秒)は満たすが、多SLD一括時の並列化・キャッシュは将来課題。

## 7. 推奨(いずれも未適用・較正とセットで判断)

1. Tranco にはインフラ系名(gstatic, akamaiedge, gtld-servers, …)が多数含まれる。ブランド視点では過剰な近傍になる場合があり、フィルタリングは将来の較正課題。
2. `www` 接辞の追加(§3)。
3. gold の実コーパス基準での再レビュー(ホールドアウト開封後)。

## 8. 方法

TS 本番実装(JS ハーネスと5,635件全数一致を確認済み)+ `getDefaultPreparedCorpus()` に対し、
gold 91件(人間確定ラベル、ambiguous 除外で90件)・red-team 確定攻撃23件・FA 実在語群・
上位100名への系統変形978件(削除/置換/転置/重複/leet/combo/missing-dot)・シード固定の発音可能造語2,000件・
ランダム500クエリの性能測定を実行した。gold セットと生成器は検証ワークスペース(uniq-lab)側にあり、
リポジトリには含まれない(検証記録は DESIGN_RATIONALE.md を参照)。

## 追記（2026-08-26、PR #155 レビュー対応）

参照コーパスからアダルト・海賊版サイト **407 件**を除外した（`packages/shared/scripts/corpus-denylist.mjs`）。
`topSimilar` の名前は候補カード・登録ダイアログ・ランディングにそのまま描画されるため、
`anime` / `manga` / `rule` のような一般的な入力で成人向けサイト名が「最も近い既存名」として
表示されていた。除外はスコア計算にも効くので、該当語の周辺スコアは上振れする（例: `manga` 44 → 57）。
除外規則はキーワード部分一致 + 誤検出の個別 allowlist（`analytics` / `java` / `myanimelist` など）で、
回帰は `packages/shared/src/uniqueness/default-corpus.test.ts` が守る。
本書の gold / 攻撃回帰の数値は除外前の測定値であり、除外後の再測定は未実施。
